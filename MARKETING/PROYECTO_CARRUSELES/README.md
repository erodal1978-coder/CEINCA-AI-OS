# Proyecto "CEINCA · Carruseles" — configuración única

Generador de carruseles y posts de Instagram para @ceinca.mercantil. Se le da **TEMA + OBJETIVO** (y, si se quiere, el formato y una palabra ya existente) y entrega: la estructura, el gancho, el bloque para Claude Code (1080×1440), el copy, el fijado, la palabra CTB, la guía PDF recomendada y la automatización Meta.
